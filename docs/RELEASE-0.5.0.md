# ReleaseHub（追新）0.5.0

## 安装完成后，可靠同步版本

- EXE/MSI 点击即打开作者安装向导，后台保存本次下载版本和待验证任务，不再要求安装后逐项填写版本。
- 核对已关联主程序版本或明确匹配的 Windows 安装记录；只有发现可信的本次目标版本才同步软件与下载记录。安装器退出、经过固定时长、上游又发布新版本，都不是成功依据。
- 明确区分等待、检测中、已验证、手动记录、等待重启、未确认、取消和失败。MSI 要求重启时，重启后再验证。
- 任务可随软件重启恢复；后续安装、手动改版本、删除记录或切为文件订阅后，旧任务不能覆盖新状态。
- 对已可靠关联的软件，定期检查外部升级；不扫描全盘、不执行探测脚本、不静默安装。绑定与机器路径仅保存在本机，不进入订阅导出。
- 不能可靠识别时保留原版本，可直接“立即检测”，或在折叠详情中一键“标记已安装本次版本”。不同作者的安装器和版本格式无法统一保证自动识别。

## 更短的日常操作

- 资源详情只展示版本、更新说明和发行文件；项目设置与备份管理各自独立。
- 修改本机版本先显示版本输入，路径与启动程序折叠；下载任务只突出当前最需要的操作，其余放入“详情 / 更多”。
- 移除应用内多余的二次确认与确认勾选。恢复、删除和切换版本直接执行，请确认自己点击的操作。
- 更新前备份改为每个软件独立选择，**默认关闭**，只在“管理备份”中开启。关闭时不创建完整快照，已有备份仍保留可用。
- 开启备份但缺少目录时必须先补充目录，不能悄悄跳过。未开启备份时安装失败可能留下部分更新文件，不会自动回退；文件备份不包含注册表与服务状态。

## 下载

- `ReleaseHub-0.5.0-windows-x64-portable.zip`：便携版，全部解压后运行，保留同目录的 `tools` 与 `integrations`。
- `ReleaseHub-0.5.0-windows-x64-setup.exe`：Windows 安装版。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。
- 源码使用本页自动生成的 Source code，或检出标签 `v0.5.0`。

已有便携版：退出追新后覆盖程序文件，**保留原有 `data` 文件夹**；不要用新包中的空目录替换原数据。数据库会自动升级，GitHub 登录与配置保持在原机器上。此版本未购买商业代码签名，Windows 可能提示未知发布者。
