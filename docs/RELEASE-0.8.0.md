## 风灵月影：在追新里查找和保存官方附件

- 最近更新、全部修改器、搜索结果和详情改用追新自己的界面，跟随浅色或深色主题。按游戏英文名搜索，进入详情查看官方附件；返回时保留搜索和滚动位置。不必切换浏览器，也可以点「官网原文」查看来源。
- 在附件旁点「另存为…」可以选择保存位置。取消不会留下文件；已保存的附件可在文件夹中显示，追新不会自动运行它。

## 资源库：自己排顺序

- 圆角排序菜单新增「手动排序」。拖动卡片手柄，或聚焦手柄后使用方向键，即可调整位置。软件和文件独立记忆顺序，重启后保留；搜索和翻页不会打乱其他项目。
- 原有的最近添加、名称升序、名称降序、最近发布和可更新优先仍可随时切换。

## 公开附件：内置下载或外部下载器

- 打开「设置 → 外部下载器」，启用「手动下载默认使用外部下载器」后，风灵月影的官方附件和 GitHub 公开发行附件都可以发给 AB Download Manager 或已配置的其他本机下载器。未订阅仓库和旧版发行附件也支持；逐个文件仍可选择内置下载。
- 「已交给下载器」不等于下载完成，进度和位置请在下载器里查看。未确认接收时不会自动重发；请先检查队列。外部下载默认关闭，自动下载仍使用内置下载。

## 下载与升级

- **Windows x64 便携版**：下载 `ReleaseHub-0.8.0-windows-x64-portable.zip`。升级前从托盘退出追新，将新版程序文件覆盖到原目录，**保留原来的 `data` 文件夹**。
- **Windows x64 安装版**：下载 `ReleaseHub-0.8.0-windows-x64-setup.exe`。
- 两个发行文件的 SHA-256 见 `SHA256SUMS.txt`；对应源码标签为 `v0.8.0`。
