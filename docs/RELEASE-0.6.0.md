# ReleaseHub（追新）0.6.0

## 官网首页动态不再频繁掉线

- **根因**：官网网页窗口的数据目录经 `canonicalize()` 变成 Windows 扩展路径（`\\?\C:\...`）。WebView2 接受该路径，但 Cookie 只保存在内存里，重启追新后官网登录随之丢失，只能重新登录并再次两步验证。
- **修复**：网页登录目录改用普通绝对路径，Cookie 正常写入本机；旧会话清理的路径比较同步修正。已在本机实测：修复前目录中始终没有 `Cookies` 数据库，修复后持久 Cookie 在强制结束进程后仍保留在磁盘上。
- **启动后静默恢复**：本机存在上次的网页登录时，进入首页或动态即在后台验证并刷新，界面显示“正在恢复官网登录…”，不弹出窗口；会话确实过期才提示登录。
- 升级后需要再登录一次官网（旧版本从未把登录写入磁盘），之后重启不再需要。

## 更简单的操作

- 首页新增“检查节奏”模块：右上角拨动开关直接开启/关闭自动检查，旋钮调节检查间隔（15 分钟～1 天，按刻度吸附），图表中的目标线实时联动，超出目标的资源以朱橙色标出，点击柱子打开详情。
- “版本更新”改为卡片堆叠：拖出顶部卡片超过阈值即展开详情，不足阈值自动归位；也可点击或回车打开。
- “退出网页”一键执行，不再二次确认；首页待安装按钮简化为“安装”。
- 外观设置只保留浅色 / 深色 / 跟随系统，移除配色方案、玻璃材质与背景模糊三组选项。

## 全界面缓存

- 启动时立即显示上次保存的本机状态，同时读取最新状态；读取完成前操作保持禁用，读取失败会提示当前为上次内容。缓存不含任何凭据，“清理页面缓存”会一并清除。
- 首页访问后常驻，与资源库、可更新、下载、GitHub 一样切换时保留内容、滚动位置与动态状态，不再重新加载。

## 新拟物界面

- 暖米白 `#F2E8E0` 底色，卡片、按钮与背景同色，仅靠左上亮影 / 右下暗影成形；按下转为内阴影。卡片圆角 24px、按键 16px，旋钮与指示灯为正圆。
- 钴蓝 `#2F4BD0` 只用于按下、开启、当前项与关键数据；告警少量使用朱橙 `#E2552D`。正文与表格保持平整。
- 侧栏菜单为键帽：悬停浮起，按下下沉 2px 并回弹，当前项保持按下并点亮蓝色指示灯。
- 指标数字为内凹窗口中的机械滚轮计数器，每一位独立滚动，低位更快，停止时轻微回弹。
- 状态变化使用 120–300ms 带轻微回弹的弹簧动画；系统“减少动画”时自动关闭。深色模式使用同一套新拟物规则的暖深色版本。

- `ReleaseHub-0.6.0-windows-x64-setup.exe`：Windows 安装版。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。
- 源码使用本页自动生成的 Source code，或检出标签 `v0.6.0`。

已有便携版：退出追新后覆盖程序文件，**保留原有 `data` 文件夹**；不要用新包中的空目录替换原数据。此版本未购买商业代码签名，Windows 可能提示未知发布者。
