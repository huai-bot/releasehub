# ReleaseHub（追新）0.4.1

本次发布完成资源库显示、软件启动记录和外部下载器修复。Windows 10/11 x64；现有订阅、备注和偏好保持兼容。

## 本次更新

- 资源库支持双列、三列、列表切换，重启后保留选择；调整卡片、详情、操作菜单及明暗主题下的阅读与键盘操作。
- 为应用设置可选的备注标题和小字号描述。有备注时以备注代替原名称；两项清空后恢复原名称。备注仅保存在追新，不改 GitHub 仓库资料。
- 选择启动 EXE 后自动记录所在文件夹，不会立即运行；已记录目录包含所选 EXE 时保留原目录。“记录已安装版本”也可一并选择启动程序并自动填入目录。
- 修复外部下载器开关的保存行为，关闭后手动下载恢复内置下载。
- AB Download Manager 预设改用 `/add` 接口；测试连接只读取 `/queues`，不会添加下载。精确识别并迁移旧默认预设，不覆盖自定义接口。
- 布局随订阅与备注导出；旧导入文件没有布局字段时保留当前选择。

## 下载与升级

- `ReleaseHub-0.4.1-windows-x64-portable.zip`：推荐便携版，全部解压后运行其中的应用程序，保留同目录的 tools 和 integrations 文件夹。
- `ReleaseHub-0.4.1-windows-x64-setup.exe`：Windows 安装版，按向导安装。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。
- 精确对应本版的源码可从本页的 Source code 下载，或检出 Git 标签 `v0.4.1`。

升级前从托盘菜单退出追新，保留原有 data 目录；不要用空数据目录覆盖现有资料。两种版本均需要 Microsoft Edge WebView2，安装版会在缺少运行环境时提示补齐。程序未购买商业代码签名证书，请核对发布来源和校验值。

## 外部下载器注意事项

AB 应先启用浏览器集成服务，默认接口为 `http://127.0.0.1:15151/add`。若启用了访问密钥，当前预设暂不支持；请保留验证并改用追新内置下载，不要为此关闭安全设置。外部发送前仍需确认，真实进度在下载器中查看；完成后导入附件并校验，再进行安装。自动下载始终使用内置下载器。
