## 资源库与本地软件

- 资源库新增最近添加、名称升序、名称降序、最近发布、可更新优先五种排序，重启后保留选择。
- 大库的排序和筛选放到后台，每页只显示 48 项，搜索仍覆盖全部资源。同机 2,000 条资源（软件、文件各 1,000 条）来回切换 10 次，中位耗时从 116.5 毫秒降为 33.5 毫秒。
- 把 EXE 拖进「资源库 → 软件」，或点「添加本地软件」，即可记录现有程序，无需复制或运行。后台可靠匹配到公开 GitHub 仓库后自动查更；未匹配的显示「本地」。卡片的「··· → 设置 GitHub 仓库」可补填、更改或解除本地程序的关联。

## GitHub 附件与风灵月影官网

- 公开仓库详情新增「查看最新附件」，可直接选择文件加入下载队列，不必先订阅仓库。阅读旧版发行说明时也可下载它对应的附件。独立下载只保存文件，不会安装。
- 侧栏新增「风灵月影」：在应用内打开官网、查看全部修改器、按游戏名搜索，选中官网附件后另存到指定位置，不会自动运行。

## 下载与升级

- **Windows x64 便携版**：下载 `ReleaseHub-0.7.0-windows-x64-portable.zip`。升级前请从托盘退出追新，覆盖原目录中的程序文件，**保留现有 `data` 文件夹**。
- **Windows x64 安装版**：下载 `ReleaseHub-0.7.0-windows-x64-setup.exe`。
- 两个发行文件的 SHA-256 见 `SHA256SUMS.txt`。源码对应标签 `v0.7.0`。
