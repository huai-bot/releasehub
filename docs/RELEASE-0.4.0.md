# ReleaseHub（追新）0.4.0

本轮集中改进 Windows 软件更新、GitHub 工作区和下载。

## 软件管理

- 首页集中显示更新、下载和待安装事项，资源库使用软件大卡片，“可更新”保留独立处理队列。
- 原目录更新前核对目录、版本、备份和可用空间；ZIP 明确选择程序目录，同名文件覆盖，其余文件保留。
- 每款软件保留最近一次成功更新的完整文件备份，恢复和删除均需确认；中断通过日志恢复。
- 首装与旧受管位置迁移选择专用空目录。EXE/MSI 先备份再打开作者向导；文件恢复不包含注册表和服务。
- 软件卡片可指定主程序并打开软件，下载页可确认清理安装包及记录，保留安装状态和备份。

## GitHub 工作区

- API 授权和官网登录分别展示，官网会话持久化，首页与 GitHub 共用动态状态。
- 仓库列表和详情独立滚动，本地名称与说明突出显示，同时保留原仓库资料。
- 启动后台预加载账号、仓库、Stars 分类和动态；各分类独立缓存，失败保留自身已读内容。
- 分类目录和仓库归属共享有效快照，预读限制并发，设置分类优先复用缓存；账号切换和分类变更使相关缓存失效。

## 下载

- 单文件连接数可选 1～8，默认 4；支持安全 Range 分段的大文件并行下载，不支持时使用单连接。
- 校验响应范围、长度、文件身份和摘要；取消或失败清理临时分片。
- 本机 JSON POST 外部下载器接口，内置 AB Download Manager 预设，可修改名称、接口和模板。
- 外部下载发送前确认，进度由外部下载器显示；完成后导入文件，校验后再安装。自动下载仍走内置下载。

## 安装文件

- `ReleaseHub-0.4.0-windows-x64-setup.exe`：Windows x64 安装版。
- `ReleaseHub-0.4.0-windows-x64-portable.zip`：解压后运行的便携版。
- `SHA256SUMS.txt`：正式产物校验值。

两种版本需要 Microsoft Edge WebView2。升级前退出正在运行的追新，保留原有数据目录；账号凭据留在本机。安装包未购买商业代码签名证书。

## 验证与构建

Windows 正式产物来自手动启动的 GitHub Actions：界面检查与测试、Rust 核心测试、信息连接器、Tauri NSIS 构建、隔离启动检查、图标和显式清单打包。新增分类缓存与共享动态测试已纳入该流程。

本轮本地已验证多尺寸明暗界面、原目录更新和恢复、分类预加载、多连接下载及外部文件导入；AB Download Manager 1.11.4 的真实本机接口成功返回 200 并完成一次公开文件下载。
