# ReleaseHub Product Definition

- **Product**: ReleaseHub (追新), a portable-first Windows 10/11 x64 GitHub release manager.
- **Audience**: Developers and power users tracking software releases.
- **Context**: Desktop-first utility (Tauri 2 / Svelte 5 / TypeScript).
- **Goal**: Clean, natural, human-centric design that avoids generic "AI template" aesthetics.
- **Quality**: Functional, accessible (keyboard/reduced motion), theme-aware, Chinese-first UI.
- **Constraints**: No paid services, no tracking, minimal local storage footprints, preserve existing business logic and security boundaries.
